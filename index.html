Widget das IAs, na linha da Fila

Agora em tamanho grande, aproveitando o espaço do iPad. Mesma linguagem que você escolheu: ícone de verdade de cada app, título, o último passo e o botão Responder quando a IA precisa de você. Os textos são de exemplo.

Quatro linhas

A Fila esticada para baixo: quatro sessões uma embaixo da outra, cada uma com duas linhas para o último passo.

Widget grande, quadrado.

Dois por dois

Quatro sessões em duas colunas e duas linhas. Com mais espaço, cada uma mostra o passo de agora e, em cinza, o passo de antes, para você ver que ela está andando.

Widget extra grande, ocupa a largura da tela deitada.

Caixas dentro da caixa

Uma caixinha por IA, lado a lado, com as sessões de cada uma dentro. Você vê de uma vez quem está trabalhando em cada app.

Widget extra grande.

Pilha

O jeito do iPad de rolar um widget: várias páginas empilhadas no mesmo lugar. A primeira é sempre o que está acontecendo agora; as outras são uma por IA. Deslize para cima e para baixo aqui no desenho.

Pilha de widgets grandes. Também funciona com o extra grande.

Deslize para cima

Nenhum widget rola por dentro: é regra da Apple. A pilha é o rolar do iPad e dá para combinar com qualquer uma das outras três, por exemplo uma pilha de caixas.

Tocar numa linha abre aquela sessão; Responder abre direto onde ela está esperando você.
